# Lagged Backtest：显式滞后回测

一个单资产、做多/现金的研究回测工具。默认信号在第 t 日收盘产生，
第 t+1 日收盘执行，从第 t+1 至 t+2 日的收益才开始计入。
每期记录信号索引、仓位、换手、费用、收益和净值，方便逐项复核。

```sh
python -m pip install .
lagged-backtest examples/prices.csv --window 3 --lag 2 --cost-bps 10
python -m unittest discover -s tests -v
```

Python 3.10 以上，无运行时第三方依赖。所有示例价格和信号都为虚构，
不代表真实收益。仓位范围为 0 至 1；交易费按换手计入；部分仓位涨跌后
会漂移，下一次按目标仓位再平衡。无终期平仓，现金收益为零。

`lag=1` 是乐观的同日收盘成交假设，使用者须自行论证可行性。
工具无法识别输入信号本身已经包含的未来信息。年化按设定的每年期数计算，
不按日历跨度；没有税费、公司行动、市场冲击或真实交易接口。
